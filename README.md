# 双水村 · 3D

《平凡的世界》双水村的可自由行走 3D 场景。
不是文字游戏，没有剧情弹窗；把你放进这个山沟里，自己走。

在线试玩：https://lighthouse-ctrl.github.io/shuangshui3d/

## 打开

双击 `index.html`，用 Chrome / Edge 打开。单文件、离线、无需服务器。

## 操作

| 键 | 动作 |
|---|---|
| W A S D / 方向键 | 走动（4.9 m/s，Shift 跑 8.8 m/s） |
| 拖动鼠标 | 转镜头 |
| 滚轮 | 拉近拉远 |
| Shift | 跑 |
| 空格 | 跳 |
| E | 靠近地点时“看看” |

手机上：左下虚拟摇杆走动，右下“看”按钮，右侧拖动转镜头。

## 场景

## 技术

- 原生 WebGL 1，没有 three.js 或任何依赖
- 地形、水面、天空、人物、建筑全部运行时生成
- 单文件约 79 KB

## 目录

```
index.html          成品（可直接打开）
src/template.html   页面 / HUD / 标签 / 小地图样式
src/game.js         引擎、地形、窑洞、人物、操作
build.mjs           把 src 内联合成 index.html
tools/smoke3d.js    无浏览器冒烟测试（假 WebGL / 2D 上下文）
preview/            截图
```

改完 `src/` 后：

```powershell
node build.mjs
```

调试参数：`?play=1` 跳过开场；`?play=1&px=30&pz=-20&yaw=1.2&pitch=0.2` 指定位置、朝向、俯仰。

## 昼夜循环 + 战斗系统

- 昼夜：进村从 16:18 开始，游戏里一天约 8 分钟；太阳、天空、雾、环境光随时辰变化，
  右上角有时钟。入夜后明显变暗，太阳落到地平线下就不再画。
- 战斗：
  - 左侧面板：血量条、当前武器、子弹数。
  - **1** 换剑，**2** 换枪；**J** 攻击；**R** 换弹（枪）。
  - 剑：近距离扇形挥砍；枪：准星命中，60 米内，8 发子弹。
  - 手机上点右下角“攻击”按钮。
- 随机刷怪：野狗会在你周围 20~40 米随机刷新，白天最多 3 只、夜里最多 6 只；
  会追你、近身咬人；血空后在村口重生，怪清空。
- 测试参数：?time=21 直接进夜晚，?mob=1 开局刷 3 只怪。
- 战斗帧已经用 10 秒的冒烟测试跑过（含怪物追击、掉血、死亡重生）。

## BGM（程序生成）

- 没有音频文件，用 Web Audio 现场合成：低音持续音（D/A/D 三个正弦）+ 稀疏的五声音阶旋律
  （三角波，带 0.42 秒回声）。
- 进村时自动开始；夜里旋律降八度，变得低沉一些。
- 左上角“音乐”按钮或按 **M** 开关；按钮文字在“音乐/静音”之间切换。
- 音量压得比较低，当背景音用。

## 天上的云

- 16 团低多边形云，飘在 82~128 米高，每团由 7 个压扁的球堆成，0.42 的竖向压扁。
- 云会缓慢向东飘，飘出 290 米就从另一侧绕回来。
- 颜色跟着光照走：白天白、黄昏发暖、夜里偏蓝灰；远处会被雾吃掉。
- 没有贴图，和整体低多边形风格一致。
## 投篮物理重做

- 球现在有重力、篮圈碰撞（打铁）、篮板反弹（打板）、地面弹跳（落地后还会弹几下）和旋转。
- 进球判定改成“从篮圈圆柱里落下”：球心在篮圈中心 0.35 米内、从上方下落穿过才算。
- 蓄力条放慢到 0.6/秒，进球窗口约 0.40~0.48（约 130 毫秒），有手感但不至于太难。
- 测试数据：0.40 进、0.42 打铁、0.44/0.46/0.48 进、0.50 没进、0.55 打铁。
- 球落地后继续弹，等停稳才出“进了/没进”的结果。
